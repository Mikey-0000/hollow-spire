# The Hollow Spire

An original turn-based RPG made with p5.js. Climb three floors of the spire, explore, and fight the Hollow Wisp, the Spire Reaper and the Abyssal King to claim the Spire Relic.

**Play:** https://mikey101101.github.io/hollow-spire/

## Controls
- WASD or arrow keys: move
- E: interact
- Enter: select

In battle you can attack, use Fire or Ice to find enemy weaknesses, drink an Elixir to restore HP and SP, or guard to reduce damage.

## Run locally
Open `index.html` in a browser. p5.js loads from a CDN, so you need an internet connection.
